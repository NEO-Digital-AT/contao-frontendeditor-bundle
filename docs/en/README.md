# NEO Frontend Editor – documentation

The NEO Frontend Editor lets editors change content directly on the page, in
Contao's own front end preview. Contao's permissions decide what each user may
do; every change is saved as a Contao version.

## Editions

Everything in the user manual marked without an edition is free (**Basic**).
**Plus** adds pages, posts, modules and language versions; **Pro** also the
writing aid, the checks for search engines and accessibility, the screen sizes
and the page style. Each page of the user manual says which edition a function
needs.
