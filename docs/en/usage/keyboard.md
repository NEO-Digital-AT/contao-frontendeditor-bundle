# Keyboard

Everything in the editor can be done without a mouse.

## On the page

| Keys | What it does |
| --- | --- |
| Tab | Moves to the next element, its frame and tab appear; from the element to its tab, from the tab on to what follows |
| Enter, Space or an arrow key on the tab | Opens the menu of the element (arrow up: on its last entry) |
| Enter on the element | Starts editing it (opens **All fields** when it has no text on the page) |
| Alt+Arrow up / down on the element or its tab | Moves the element |
| Delete on the element or its tab | Deletes the element (after a question) |
| Arrow keys, Home, End, Enter in a menu | Choose an entry; Esc closes the menu and goes back to the tab, Tab closes it |
| Ctrl+S (Cmd+S) | Saves every waiting change |
| Ctrl+click (Cmd+click) on a link | Follows the link; a click without the key does not lead away |
| Esc | Leaves the text you are writing in (the change waits); a second Esc ends the selection; closes a card, a menu or a dialog |
| Context-menu key or Shift+F10 | Opens the editor's menu of what has the focus (or of the text you are writing in); the browser's menu does not open in the page (for its spelling suggestions: a second right click in the text you are writing in, see [Editing](editing.md#the-context-menu)) |

## In the sidebar (structure)

| Keys | What it does |
| --- | --- |
| Arrow up / down | Next or previous row |
| Home / End | First or last row |
| Enter | Starts editing the selected element (opens **All fields** when the element has no text on the page) |
| Alt+Arrow up / down | Moves the element |
| Delete | Deletes the element (after a question) |
| Shift+F10 | Opens the menu with all actions of the element |

## Elsewhere

| Keys | What it does |
| --- | --- |
| Arrow keys on the left edge of the sidebar | Changes its width |
| Esc in the bar of a **Screen size** | Back to the normal width |
| Tab in a card ("Info") | Stays inside the card until it is closed |
