# NEO Frontend Editor – Dokumentation

Mit dem NEO Frontend Editor ändern Redakteure Inhalte direkt auf der Seite, in
Contaos eigener Frontend-Vorschau. Contaos Rechte entscheiden, was jeder
Benutzer darf; jede Änderung wird als Contao-Version gespeichert.

## Stufen

Was in der Bedienungsanleitung ohne Stufe steht, ist kostenlos (**Basic**).
**Plus** bringt Seiten, Beiträge, Module und Sprachversionen dazu, **Pro**
zusätzlich die Schreibhilfe, die Prüfungen für Suchmaschinen und
Barrierefreiheit, die Bildschirmgrößen und den Stil der Seite. Jede Seite der
Bedienungsanleitung nennt die Stufe, die eine Funktion braucht.
