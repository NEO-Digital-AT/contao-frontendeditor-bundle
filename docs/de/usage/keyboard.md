# Tastatur

Alles im Editor geht auch ohne Maus.

## Auf der Seite

| Tasten | Was sie tun |
| --- | --- |
| Tab | Springt zum nächsten Element, sein Rahmen und sein Reiter erscheinen; vom Element zu seinem Reiter, vom Reiter weiter zu dem, was folgt |
| Enter, Leertaste oder eine Pfeiltaste auf dem Reiter | Öffnet das Menü des Elements (Pfeil nach oben: auf seinem letzten Eintrag) |
| Enter auf dem Element | Beginnt das Bearbeiten (öffnet **Alle Felder**, wenn das Element keinen Text auf der Seite hat) |
| Alt+Pfeil nach oben / unten auf dem Element oder seinem Reiter | Verschiebt das Element |
| Entf auf dem Element oder seinem Reiter | Löscht das Element (nach einer Rückfrage) |
| Pfeiltasten, Pos1, Ende, Enter in einem Menü | Einen Eintrag wählen; Esc schließt das Menü und geht zurück zum Reiter, Tab schließt es |
| Strg+S (Cmd+S) | Speichert alle wartenden Änderungen |
| Strg+Klick (Cmd+Klick) auf einen Link | Folgt dem Link; ein Klick ohne Taste führt nicht weg |
| Esc | Verlässt den Text, in dem Sie schreiben (die Änderung wartet); ein zweites Esc hebt die Auswahl auf; schließt eine Karte, ein Menü oder einen Dialog |
| Kontextmenü-Taste oder Umschalt+F10 | Öffnet das Menü des Editors für das, was den Fokus hat (oder für den Text, in dem Sie schreiben); das Menü des Browsers öffnet sich in der Seite nicht (für seine Rechtschreibvorschläge: ein zweiter Rechtsklick in den Text, in dem Sie schreiben, siehe [Bearbeiten](editing.md#das-kontextmenü)) |

## In der Seitenleiste (Struktur)

| Tasten | Was sie tun |
| --- | --- |
| Pfeil nach oben / unten | Vorherige oder nächste Zeile |
| Pos1 / Ende | Erste oder letzte Zeile |
| Enter | Beginnt das Bearbeiten des gewählten Elements (öffnet **Alle Felder**, wenn das Element auf der Seite keinen Text hat) |
| Alt+Pfeil nach oben / unten | Verschiebt das Element |
| Entf | Löscht das Element (nach einer Rückfrage) |
| Umschalt+F10 | Öffnet das Menü mit allen Aktionen des Elements |

## Anderswo

| Tasten | Was sie tun |
| --- | --- |
| Pfeiltasten am linken Rand der Seitenleiste | Ändern ihre Breite |
| Esc in der Leiste einer **Bildschirmgröße** | Zurück zur normalen Breite |
| Tab in einer Karte („Info“) | Bleibt in der Karte, bis sie geschlossen wird |
