# Bedienungsanleitung

In der Reihenfolge, in der sie meist gebraucht wird. Jede Seite nennt die Stufe,
die eine Funktion braucht (Basic ist kostenlos, Plus und Pro brauchen eine
Lizenz), und was zu tun ist, wenn etwas nicht funktioniert.

| [Struktur ändern](structure.md) | Elemente einfügen, verschieben, duplizieren, ausblenden und löschen, Artikel, Elemente in Elementen |

| [Sprachen (Plus)](languages.md) | Sprachversionen nebeneinander, Übersetzungsvorschläge, veraltete Übersetzungen |
| [Schreibhilfe (Pro)](writing-aid.md) | Drei KI-Vorschläge für eine Überschrift oder einen Text |
| [Prüfen und Bildschirmgrößen (Pro)](check.md) | SEO mit Punktzahl und Fokus-Suchbegriff, Barrierefreiheit, die Seite in der Breite eines Handys oder Tablets |
